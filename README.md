# OutcomeCI Homebrew tap

Homebrew formulae for OutcomeCI command-line tools.

## Install

```sh
brew install outcomeci/tap/outcomeci-cli
```

or tap once and install by name:

```sh
brew tap outcomeci/tap
brew install outcomeci-cli
```

## Formulae

| Formula | Description |
|---------|-------------|
| `outcomeci-cli` | The `oci` command for portable Standup and outcome workflows. |

## Maintenance

Formulae are updated from published PyPI releases by the OutcomeCI CLI release
pipeline.
